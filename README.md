# B站注意力伴侣｜防沉迷胶囊

一个在哔哩哔哩网页端运行的轻量 Tampermonkey 用户脚本。通过悬浮胶囊、评论区计时、浏览行为提醒与本地统计，帮助用户更有意识地使用 B站，而不是简单地屏蔽网站。

> 当前脚本版本：**3.0.0**。本项目用于个人时间管理和辅助观察；所有分类、时长与干预效果均为规则或行为信号产生的估计，不等于内容真伪判断，也不等于准确测量注意力。

## 功能

- **悬浮胶囊**：在网页显示当日有效浏览时长、视频数量、当前分类与评论区时间；支持拖动位置和紧凑显示。
- **评论区提醒**：默认阅读约 120 秒轻提醒，180 秒强提醒；可根据设置折叠或恢复评论区。
- **浏览节奏提示**：根据短时间内切换视频、反复进入评论区等行为触发低打扰提醒。
- **视频主题与表达类型分类**：使用标题、分区、标签等信号进行本地规则识别；允许手动修正。
- **标题与公共议题提示**：针对部分值得进一步核查的措辞给出提示，不直接判定立场、质量或事实真假。
- **时间预算与模式**：支持普通、学习、娱乐模式，以及评论区、连续浏览、每日浏览等阈值设置。
- **本地统计与七日报告**：展示最近 7 天的有效浏览时间、视频类别、评论占比与提醒记录。
- **手动控制**：支持暂停提醒、暂停视频、结束本次浏览、重置连续会话等操作。

## 安装方法

1. 在浏览器中安装并启用 [Tampermonkey](https://www.tampermonkey.net/) 扩展，并确认浏览器允许用户脚本正常执行。
2. 在本仓库打开 [`Bilibili-Focus-Capsule.user.js`](./Bilibili-Focus-Capsule.user.js)。
3. 点击文件页面的 **Raw（原始文件）** 按钮；如浏览器未自动出现 Tampermonkey 安装页，可复制 Raw 页面地址，在 Tampermonkey 的“从 URL 安装”功能中使用。
4. 在 Tampermonkey 中检查脚本名称、作用域和权限，点击安装。
5. 打开 [B站首页](https://www.bilibili.com/) 或视频页，查看是否出现「B站注意力伴侣」悬浮胶囊。

如果已经安装旧版本，请先备份个人设置并留意 Tampermonkey 对同名脚本的更新/替换提示，不要把新旧两个版本同时启用，以免双重计时、重复提醒。

## 支持页面

当前脚本的匹配范围：

- `https://www.bilibili.com/*`
- `https://search.bilibili.com/*`
- `https://space.bilibili.com/*`
- `https://live.bilibili.com/*`

不同页面的统计与识别能力可能不同。B站前端改版可能影响部分评论区域和视频元数据的识别。

## 常用设置

点击悬浮胶囊 → **设置**，可以调整：

| 设置项 | 默认值 |
| --- | --- |
| 评论区轻提醒 | 120 秒 |
| 评论区强提醒 | 180 秒 |
| 连续浏览提醒 | 15 分钟 |
| 每日使用提醒 | 45 分钟 |
| 无操作暂停阈值 | 70 秒 |
| 本次预算 | 30 分钟 |
| 统计保留期 | 14 天，可改为 30 天 |
| 读取 B站视频信息 | 开启，可关闭 |

所有时间统计均有估算误差，尤其是在后台播放、浏览器休眠、页面切换等情况下。

## 数据与隐私

- 统计及用户手动分类主要保存在 Tampermonkey 的本地脚本存储中。
- 脚本声明的跨站请求权限仅允许访问 `api.bilibili.com`，可选地从 B站官方视频信息接口读取标题、分区等元数据。
- 不需要注册额外账号或部署服务器，也未在代码中配置第三方统计服务。
- 不以评论正文和输入框文字作为统计数据保存。
- 可在设置中清除统计数据；注意这项操作不能撤销。

发布代码前仍应自行检查是否包含个人令牌、账号信息或私有配置。公开仓库中的提交历史可长期保留曾上传的内容。

## 使用限制

- 本工具不替用户判断哪些内容“有价值”，更不会依据标题直接认定事件真假或政治立场。
- 网站DOM结构变化、浏览器限制、不同用户的设置会影响统计和提醒。
- 结束本次浏览不代表自动关闭浏览器标签页。
- 当前版本没有配置 `@updateURL` / `@downloadURL`，发布者应在确定自己的 GitHub 仓库地址后再配置并测试自动更新；现在可以手动从本仓库安装新版。
- 功能来自所提供的 v3.0.0 源码，尚未在真实 B站页面上完成本次发布包的端到端验证。
